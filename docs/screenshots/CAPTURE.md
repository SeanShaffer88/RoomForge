# Screenshot capture list

Screenshots for the README are taken from **real runs on SEAN's Windows
machine**. Do not use placeholder, stock or generated images. Wire each
capture into `README.md` as soon as it is supplied.

## Capture settings (all shots)

- Display scaling: **100%**
- Theme: dark (the standard black/red RoomForge theme)
- Window size: **1600×1000 or larger**, window maximised or sized to
  at least 1600×1000
- Use the same example room and plan for shots 1–3, so the views match
- Save as PNG, named exactly as listed below, in this folder

## Captures

1. **Main window — 2D plan with furniture**
   - File: `01-2d-plan.png`
   - The main window showing a room in the 2D plan view, with walls,
     at least one door and one window, and several pieces of furniture
     placed. The catalogue panel and measurements should be visible.

2. **3D view — same room**
   - File: `02-3d-view.png`
   - The same room and furniture as shot 1, shown in the 3D view,
     at an angle where the layout is clearly readable.

3. **Item list panel**
   - File: `03-item-list.png`
   - The item list view/panel for the same room, listing the placed
     items. No prices appear — that is expected and correct.

4. **Room setup / openings panel**
   - File: `04-room-setup.png`
   - The room setup panel showing room dimensions and the controls for
     adding openings and fixed points (doors, windows, sockets,
     pipes/water points, radiators).
